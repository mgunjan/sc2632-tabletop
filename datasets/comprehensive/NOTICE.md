# Source attribution and use

This directory contains original collection/normalization tools, immutable source records, and retained upstream notices. Imported content in the local corpus retains each source's original copyright and applicable license; the project-level Apache license does not replace those terms.

See `sources.lock.json` and `licenses/<source>/` for exact repository identities, notice hashes and license copies. Most sources use Apache-2.0. Atomic Red Team uses MIT; Sigma rules use Detection Rule License 1.1; MITRE ATT&CK uses its own retained license and attribution requirements. Nested files and third-party material can have additional notices. PolicyBench retains its original corpus-provenance references.

Raw captures, recorded event payloads, source checkouts, binaries and the full normalized corpus stay in the ignored local cache. The public source package includes the tools, manifests and source-specific notices. Fetch from pinned originals for the complete local collection. No imported raw corpus is relicensed as a single Apache-only dataset.

Original execution output and derived test expectations retain their separate provenance. No upstream project endorses this collection or the resulting models.
